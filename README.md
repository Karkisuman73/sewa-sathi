# Sewa-Sathi

Sewa-Sathi is a simple platform that helps users find and explore 
different services in one place. Users can browse service categories, 
search for services, and view service details through an easy-to-use and responsive interface.

## Features

- Responsive header and navigation
- Mega menu with service categories
- Hero section with call-to-action
- Service search functionality
- Service/category cards
- Service details
- FAQ accordion
- Responsive mobile navigation
- CTA section
- Footer
- Custom 404 page
- Responsive desktop, tablet, and mobile layouts

## Tech Stack

- React
- Vite
- JavaScript
- CSS / Tailwind CSS
- Lucide React
- React Icons
- React Router


## Getting Started
git clone <https://github.com/Karkisuman73/sewa-sathi.git>
cd sewa-sathi
npm install
npm run dev

## Technical Approach

The UI is divided into reusable components such as Navbar, Mega Menu, 
Search, Hero, Service Cards, FAQ, CTA, and Footer. 
Service and category data are maintained separately in local data files 
to keep the components reusable and easy to maintain.

Responsive layouts are implemented for desktop, tablet and mobile
screens.

## AI Usage

AI development assistants were used for brainstorming,
implementation assistance and debugging. The final implementation
was reviewed, modified and tested manually.
